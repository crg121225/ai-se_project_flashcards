# Flashcard Carousel

A single-page flashcard study app that lets you browse decks and review cards in a carousel-style interface on GitHub Pages.

## Features

- Deck gallery view with color-coded deck cards
- Hash-based navigation between home, about, carousel, and not-found views
- Card carousel with previous, next, and flip interactions
- Dynamic deck rendering from JavaScript data
- Responsive layout for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)
- Normalize.css
- Git and GitHub Pages
